# Gap analysis

## Initial state

The repository contained no tracked files or commits. The user brief required a generator—not an extension—supporting WXT first, Plasmo second, separate-target copying, target-side setup/start scripts, testing/tooling guidance, advanced API/AI/WebSocket/Rust direction, and agent instructions.

## Delivered

- Safe root menu, host doctor, non-interactive generator, dry run, target validation, and lifecycle-command guards.
- Shared generated-target tooling plus complete WXT and Plasmo TypeScript/React starters.
- Standard/minimal profiles and npm/pnpm/yarn/bun selection.
- Tailwind and local shadcn-style component foundations appropriate to each bundler.
- Messaging, storage, background/content/popup entry points, service clients, unit tests, and Playwright configuration.
- Chrome/Firefox verify, development, build, and package commands.
- Root/generated agent guides, security rules, architecture, framework decision guidance, resource links, and publishing checklists.
- Builder tests for both frameworks, dry runs, occupied-target preservation, root-boundary enforcement, and blocked lifecycle commands.

## External gates

- First store listings, privacy disclosures, credentials, signing, submission, and review are product/account operations and are not performed here.
- Safari conversion requires macOS/Xcode and a native wrapper.
- Live AI/API/WebSocket behavior requires a real backend and authentication design.
- Playwright E2E requires a managed browser download and interactive browser execution.
- Rust/WASM remains an optional integration because crate/toolchain choices depend on product computation needs.
- Framework/package versions must be refreshed deliberately over time; generated projects are pinned for reproducibility.
